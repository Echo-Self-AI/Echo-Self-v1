# EchoSelf — Project Overview

## Goal

EchoSelf captures, synthesizes, and authenticates a user's voice in a fully local, privacy-first system. The project produces a working AI digital twin pipeline that processes speech, generates new speech in an enrolled user's voice, embeds watermarks for provenance, and logs all events in a tamper-evident audit trail.

## Motivation

As voice-based AI systems proliferate, two problems become urgent:
1. **Identity ownership**: synthesized speech can be misattributed or used without consent.
2. **Provenance verification**: there is no lightweight, free, on-device way to prove whether a given audio clip was generated by a specific system.

EchoSelf addresses both by: (a) requiring explicit voice consent before any synthesis, (b) embedding per-generation watermarks, and (c) maintaining an append-only audit log.

## Design Principles

**Local-first privacy**: all audio processing happens on-device. No audio is transmitted to external services.

**Consent gates**: every voice synthesis and speaker verification call checks the `VoiceConsentManager` before proceeding. Consent can be revoked at any time, and all subsequent synthesis attempts raise `PermissionError`.

**Free tools only**: the entire system is implemented using PyTorch, Python, and the Go standard library. Total cost: ₹0.

**Hardware-aware**: designed for RTX 3050 (3.7 GB VRAM). All models fit in available memory, with CPU fallback.
